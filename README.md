About the Project

Planova is a desktop-based Event Booking System developed using C# Windows Forms. The system is designed to provide users with a simple and easy-to-use way to
  create accounts, browse events, view event details and ticket prices, select tickets, manage their cart, and complete a booking through the payment process.
  The project was developed as a group project, with team members contributing to different parts of the system including the user interface, event management,
  user accounts, shopping cart, and booking/payment process.

Main Features

* User registration and login
* Browse available events
* View event details, dates, times, and locations
* View ticket prices
* Add and remove tickets from the cart
* Update ticket quantities
* Calculate cart total
* Payment process
* Booking confirmation

⚠️ FontAwesome.Sharp

Planova uses FontAwesome.Sharp for the icon buttons used throughout the application.
If you encounter errors with `IconButton`, missing FontAwesome references, or icons not displaying correctly after cloning the repository, reinstall the NuGet package:

`FontAwesome.Sharp`

### Reinstalling FontAwesome.Sharp

1. Open the Planova project in **Visual Studio**.
2. Go to *Tools → NuGet Package Manager → Manage NuGet Packages for Solution.
3. Search for:
   `FontAwesome.Sharp`
4. Install/reinstall the package for the Planova project.
5. Make sure the project is using the correct version of the package.
6. *Build → Rebuild Solution.

If the `IconButton` controls still show errors, close and reopen Visual Studio after reinstalling the package.
